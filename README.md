# GlassType Beta distribution

This public repository contains GlassType test builds and SideStore source metadata. Application source code remains in the private development repository.

## Add the Beta source

Open this link on an iPhone with SideStore installed:

[Add GlassType Beta to SideStore](sidestore://source?url=https%3A%2F%2Fraw.githubusercontent.com%2Falexlark920-web%2FGlassType-Release%2Fmain%2Fsources%2Fbeta.json)

Or add this raw JSON URL in SideStore → Sources → Add Source:

`https://raw.githubusercontent.com/alexlark920-web/GlassType-Release/main/sources/beta.json`

The current Beta is GlassType 1.16.80 (build 80). Updated Russian and Ukrainian layouts (ъ and ї on long-press), synchronized App Group ID and memory management improvements. It is an unsigned test IPA; install and re-sign it through SideStore, and keep/register the keyboard extension during installation. Enable GlassType under iOS Settings → General → Keyboard.

Beta and Stable listings use the same app bundle identifier and cannot be installed side by side. Free Apple IDs are subject to SideStore's app-ID and signing limits.

## Support

GlassType is an offline keyboard with English, Russian and Ukrainian layouts, local suggestions, glide typing, emoji search, configurable touch feedback and a Liquid Glass-inspired interface. This build is for testing; successful CI checks do not replace installation and device testing.
